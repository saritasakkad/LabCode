Les Fonctions Usuelles

Nombres :
Math.round(), Math.floor(), Math.random(), parseInt(), Number()
chaînes de caractères :
toUpperCase(), includes(), split(), replace(), trim()
tableaux :
push(), map(), filter(), reduce(), find(), forEach()
objets :
Object.keys(), Object.values(), Object.entries()

Fonctions Nombre

Exemple :

const notes = [14, 15, 12, 17];
const moyenne = notes.reduce((a, b) => a + b, 0) / notes.length;

console.log(moyenne);             // 14.5
console.log(Math.round(moyenne)); // 15 


Math.round(x) arrondit un nombre à l’entier le plus proche (.5 et plus → vers le haut).

Fonctions Chaine De Caractères

Exemple :

console.log("bonjour".toUpperCase()); // "BONJOUR"

toUpperCase() met une chaîne de caractères en majuscules.

Fonctions Tableaux

Exemple :

[1, 2, 3].forEach(n => console.log(n * 2)); // 2, 4, 6

forEach() exécute une fonction pour chaque élément d’un tableau.

Fonctions Objet

Exemple :

const user = { nom: "Léa", age: 25 };
console.log(Object.keys(user)); // ["nom", "age"]

Object.keys() renvoie un tableau contenant les clés d’un objet.
