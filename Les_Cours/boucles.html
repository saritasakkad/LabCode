Les Boucles

Boucle whil & for, comprendre un compteur break & continue, do whil.

La boucle while

La syntaxe :

while (condition) {

}

La boucle continue tant que la condition est vraie.

Exemple

let compteur = 1;

while (compteur <= 5) {
  console.log(compteur);
  compteur++;
  
}
