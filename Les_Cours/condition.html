Les Conditions

Une condition permet d’exécuter du code seulement si quelque chose est vrai : if (age >= 18) { ... }.

Les conditions

La syntaxe :


On la complète avec else if (autre cas) et else (tous les autres cas).

}

Exemple

if (age >= 18) {
  console.log("Majeur");
} else {
  console.log("Mineur");
}



On compare avec === (égal), !== (différent), >, <, >=, <=. On évite ==, qui convertit les types.
